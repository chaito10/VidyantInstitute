# Prerequisites — Vidyarthi Platform Orientation

- A personal computer with a web browser and Python ≥ 3.13.
- No server, no account, and no AI API key required for lessons 1–2 and quizzes
  (local-first: the core learning loop works offline, §1.3).
- Optional for lessons 3–4: one BYOK provider — either a local endpoint
  (Ollama / llama.cpp) or a hosted API key you control (§4.1).
- No blockchain wallet, no tokens, no cryptocurrency — none are used (§8.4).
