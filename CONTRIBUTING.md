# Contributing to Vidyarthi

Thank you for your interest in contributing to Vidyarthi (repo `charudatta10/VidyantInstitute`)! We welcome all contributions, from bug reports to new features.

## How to Contribute

To contribute, please follow these steps:

1.  Fork the repository.
2.  Create a new branch for your changes.
3.  Make your changes (see the spec in `white_paper.md`, sourced from `Vidyarthi_White_Paper.docx`).
4.  Run the checks: `python scripts/validate_course.py courses/cybersecurity-101` and `python -m pytest tests/ -q`.
5.  Submit a pull request.

## Code of Conduct

Please note that this project is released with a Contributor Code of Conduct. By participating in this project you agree to abide by its terms.
