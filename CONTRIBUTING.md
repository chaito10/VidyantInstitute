# Contributing to Vidyarthi

Thank you for your interest in contributing to Vidyarthi! We welcome all contributions, from bug reports to new features.

## How to Contribute

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes (see the spec in `docs/DECISIONS.md` and `white_paper.md`).
4. Run the checks: `python scripts/validate_course.py courses/cybersecurity-101` and `python -m pytest tests/ -q`.
5. Submit a pull request.

## Code of Conduct

By participating, you agree to abide by the project's Contributor Code of Conduct.
